# Домашнее задание: Первые шаги с Ansible

## Описание задач

В данной лабораторной работе были поставлены следующие задачи:

1. Необходимо использовать модуль `yum`/`apt` для установки пакетов
2. Конфигурационные файлы должны быть взяты из шаблона Jinja2 с переменными
3. После установки nginx должен быть в режиме `enabled` в systemd
4. Должен быть использован `notify` для старта nginx после установки
5. Сайт должен слушать на нестандартном порту — 8080, для этого использовать переменные в Ansible

## Решение

### Установка и настройка Nginx (nginx.yml)

**Что делает playbook:**

- Устанавливает nginx используя модуль `apt`
- Создает конфигурацию nginx из шаблона Jinja2 `templates/nginx.conf.j2` с переменными:
  - `nginx_port: 8080` — порт для прослушивания
  - `nginx_server_name` — имя сервера
  - `nginx_root` — корневая директория сайта
  - `nginx_index` — индексный файл
  - `nginx_access_log` и `nginx_error_log` — пути к логам
- Использует handler с `notify` для автоматического перезапуска nginx при изменении конфигурации
- Включает nginx в автозагрузку systemd (`enabled: yes`)

**Результат:** Nginx установлен и настроен, слушает на порту 8080, конфигурация управляется через шаблон Jinja2 с переменными, сервис включен в автозагрузку systemd.

## Структура проекта

```
OTUS/
├── templates/
│   └── nginx.conf.j2           # Шаблон конфигурации Nginx (Jinja2)
├── nginx.yml                   # Playbook для установки и настройки Nginx
├── invent.yml                  # Инвентарь Ansible
└── README.md                   # Документация
```

## Использование

Запуск playbook:

```bash
ansible-playbook -i invent.yml nginx.yml
```
